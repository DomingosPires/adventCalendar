Advent Calendar — Quickstart

Add the metaobject-driven advent calendar section to an existing Shopify theme. Happy path, by hand in the Admin. Full reference: INTEGRATION.md.

Before you start

  • A staff account with access to Settings → Custom data (metaobjects) and Online Store → Themes.
  • The theme you will edit — duplicate it first (Themes → ⋯ → Duplicate) so you work on a copy, then publish when happy.
  • The shopify-advent-calendar/ folder from this project. Only four subfolders go into the theme: sections/, snippets/, assets/, locales/.

1 · Add the section files to the theme

Online Store → Themes → ⋯ → Edit code on your working copy. Add each file below with Add a new section / snippet / asset and paste its contents from shopify-advent-calendar/<folder>/<file>.

In the themeFiles to add
sections/advent-calendar.liquid
snippets/advent-door.liquid, advent-overlay.liquid, advent-grid-defaults.liquid, advent-motif.liquid, advent-snow.liquid
assets/advent-calendar.css, advent-calendar.helpers.js, advent-calendar.js
locales/en.default.json, en.default.schema.json
Locales: your theme almost certainly already has en.default.json and en.default.schema.json. Do not overwrite them — open each, and merge in the single key: 
{ "sections": { "advent_calendar": { "no_entry": "Select an Advent calendar entry in the section settings." } } }
Both files can carry the same key.

Faster alternative With Shopify CLI: shopify theme push --theme <id> --only "sections/advent-calendar.liquid" --only "snippets/advent-*" --only "assets/advent-calendar.*" --only "locales/*". Never push the whole folder over a live theme.

2 · Create metaobject definition — advent_calendar_day

Settings → Custom data → Metaobjects → Add definition. Name it Advent Calendar Day; confirm the type handle is exactly advent_calendar_day. Add these fields (the key must match exactly):

KeyTypeRequiredValidation
dayIntegerYesmin 1, max 25
titleSingle line textYes—
messageRich textYes—
codeSingle line textNo—
motifSingle line textNoPreset choices (10, below)
imageFileNoImages only
link_urlURLNo—
link_labelSingle line textNo—
grid_areaSingle line textNo— (layout override, step 7)
grid_area_mobileSingle line textNo—

motif preset choices, exactly these ten, in order: wreath, candle, star, gift, tree, bell, snowflake, stocking, bauble, candycane. Empty / unknown falls back to wreath. There is deliberately no size field — a door's size is the two span values inside grid_area.

3 · Create metaobject definition — advent_calendar

Add definition → name Advent Calendar, handle advent_calendar.

For days: add field → Metaobject → turn on List of entries → point the reference at the Advent Calendar Day definition.

4 · Turn on storefront access

For both definitions: open the definition → Storefront access (a.k.a. Access → Storefronts) → enable Web. Without this the section renders nothing.

5 · Create the 25 day entries + the parent

  1. Advent Calendar Day → Add entry, once per day. Set day to the number, fill title, motif, message (type straight into the rich-text editor — plain paragraphs are fine), and code where wanted. Leave grid_area / grid_area_mobile empty to use the built-in mosaic. Set status Active. Use the default content below (ported from the React version) as a starting point, or write your own.
  2. Advent Calendar → Add entry. Fill heading (+ any colours / show_snow / start_date). In days, add all 25 day entries in order 1 → 25. Status Active.
Script alternative From shopify-advent-calendar/ with Node ≥ 18 and a custom app token (write_metaobject_definitions, write_metaobjects, read_metaobjects): cp scripts/.env.example scripts/.env, fill it in, then npm run create-defs and npm run seed — this does steps 2, 3 and 5 for you (still verify step 4). See INTEGRATION.md §6.

Parent entry (advent_calendar) defaults: heading "Calendário do Advento", subheading "Abre uma porta por dia até ao Natal", background_type solid, colours as in step 3, show_snow on, start_date empty.

6 · Add the section to the theme

  1. Online Store → Themes → Customize on your working copy.
  2. Pick a template (or a section group that accepts sections) → Add section → “Advent calendar”.
  3. In the section settings, under Content, set Advent calendar to the parent entry from step 5. If the picker is missing on your theme version, use the “…or entry handle” text field and type the entry's handle (e.g. advent-calendar-default).
  4. Save.

7 · Check it, then publish

  • Preview day (section setting): set 1–25 to walk the doors through locked → today → past; 0 = real date.
  • ?day=13 on the preview URL: client-side override to test outside December.
  • Open a door → the overlay animates from it; Esc / clicking the backdrop closes it; opened doors are remembered per browser.
  • Layout tweaks: to move or resize a door, set its grid_area to "<row> / <col> / span <height> / span <width>" (1-based; e.g. 1 / 5 / span 2 / span 1). Turn on Show layout guides in the section settings to see holes / overlaps flagged. Grid size is fixed at 7×8 desktop / 4×14 mobile in the settings; if you change it, re-balance every door. Full table + rules: INTEGRATION.md §8.
  • Colours: the section's Style overrides beat the metaobject colour fields, which beat the built-in defaults. Keep text-on-background and door-text-on-door at WCAG AA.
  • Background: set background_type on the calendar entry to solid, gradient, or image; only that type's fields apply. For an image, raise background_image_dim until text is legible. Full detail: INTEGRATION.md §9.1.
  • Custom door icons: pick another of the ten motif values, or add your own SVG / put an image on the door face — INTEGRATION.md §10.
  • When it looks right: Themes → ⋯ → Publish the working copy.

If something's wrong

SymptomCheck
Section shows “Select an Advent calendar entry…”Step 6.3 — the Advent calendar setting (or handle fallback) is not pointing at the parent entry.
Section renders nothing / blankStep 4 — storefront access not enabled on one or both definitions. Also confirm the parent entry and its 25 days are Active, not draft.
All doors locked in DecemberExpected before day 1, or if start_date is a future date. Use Preview day to check.
Wrong icon on a doormotif value must be one of the ten preset choices (step 2), lowercase. To add your own icon: INTEGRATION.md §10.
Doors overlap / gaps in the gridA custom grid_area broke the tiling. Turn on Show layout guides; clear the field to fall back to the default.
Theme editor didn't update after editing a metaobjectMetaobjects are a separate Admin screen — go back to Customize and refresh the preview.
